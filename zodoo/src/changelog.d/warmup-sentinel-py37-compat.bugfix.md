Fix `signal_warmup_done()` on Python 3.7 (legacy Odoo 11 image). The proxy-gate sentinel was cleared via `Path.unlink(missing_ok=True)`, but the `missing_ok=` keyword is Python 3.8+. The TypeError was silently swallowed by the `except`, so the sentinel was never removed and the bundled nginx proxy gated all external traffic after every container start — visible only as a `Could not clear warmup gate sentinel: unlink() got an unexpected keyword argument 'missing_ok'` warning in the odoo log.
