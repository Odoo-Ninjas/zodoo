`odoo setup upgrade` now checks GitHub Actions before upgrading: if pipelines are currently queued/running on `main` (a new release is likely minutes away), it lists them and asks whether to upgrade anyway (default no), so you can wait and jump straight to the new release. Skipped under `ZODOO_DEVMODE`/`ZODOO_ALPHA` (those track a branch, not releases) and in non-interactive shells (warning only). Uses the public GitHub API without authentication and never blocks the upgrade on network/rate-limit errors.
